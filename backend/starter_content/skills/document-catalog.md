# Каталог документов и типовых форм

Все названия и адреса example.test ниже демонстрационные. Администратор заменяет их актуальными данными или убирает неприменимые строки. Не выдавай примеры за действующие ресурсы.

| Название | Ссылка или точное имя загруженного шаблона | Когда давать |
| --- | --- | --- |
| Демонстрационный порядок согласования договоров | https://example.test/docs/contract-review | Вопрос о договорном процессе |
| Демонстрационная политика закупок | https://example.test/docs/procurement | Вопрос о выборе поставщика |
| Тестовая карточка организации | https://example.test/docs/company-card | Запрос собственных реквизитов |
| Тестовый комплект для контрагентов | https://example.test/docs/counterparty-pack | Запрос корпоративных документов |
| Тестовый чек-лист анализа договора | https://example.test/docs/contract-checklist | Поиск внутреннего чек-листа |
| Тестовый договор поставки | https://example.test/forms/supply | Типовая форма для примера |
| Тестовое приложение к договору услуг | https://example.test/forms/services-annex | Образец для примера |

Укажи статус формы и связанные приложения в столбце назначения. Выдавай только действующую ссылку или маркер [[ШАБЛОН: точное имя файла]] при совпадении с доступным файлом. По содержанию регламентов опирайся на загруженные фрагменты, поскольку ссылка сама по себе не даёт текста.

- [ПОДРАЗДЕЛЕНИЕ И КОНТАКТ] — контакт для правовых вопросов.
- [ПОРЯДОК СОГЛАСОВАНИЯ] — название и ссылка на утверждённый порядок.
- [ВЛАДЕЛЕЦ КАТАЛОГА] — ответственный за актуальность записей.

Для возврата и замены используй отдельный скилл «Возврат и замена товара потребителю».
